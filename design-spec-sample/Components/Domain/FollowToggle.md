# FollowToggle

팔로우 ↔ 팔로잉 이진 상태(on/off) 토글. 텍스트 + (팔로잉 시) 체크 아이콘. 도메인 engagement 액션.

> - [DESIGN_SYSTEM_SPEC.md](../../DESIGN_SYSTEM_SPEC.md) — 전체 원칙
> - [SPEC §11.1 분류](../../DESIGN_SYSTEM_SPEC.md#111-분류) — 카탈로그 위치

---

## 속성

| 항목 | 타입 | 기본값 | 비고 |
|------|------|--------|------|
| `isOn` | 외부 상태 (`Bool` 양방향) | — | 필수. on(팔로우) / off(팔로잉). 토글 탭 시 전환. |

## 불변 규칙

- *상태 외부 보유* — on/off 는 호출 측 보유, 토글은 표시·전환만.
- *on(팔로우)* — 브랜드 약한 배경, 테두리·아이콘 없음. *off(팔로잉)* — 표면 배경 + 테두리 + 체크 아이콘.
- *색·치수는 토큰* — `FollowToggleToken`. 라벨("팔로우"/"팔로잉")은 현재 baked(i18n 검토 대상).
