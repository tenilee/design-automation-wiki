# Shade

콘텐츠 위에 얹는 **방향성 그라데이션 스크림**. 투명에서 약한 음영으로 페이드해 그 위 콘텐츠(텍스트·아이콘)의 가독성을 높인다. 라벨·상호작용 없음.

## 역할과 범위

표면(이미지·썸네일 등) 위에 얹어 음영 그라데이션을 더하는 *비상호작용* Display 요소. 색은 *투명 ↔ 약한 음영* 으로 토큰에 고정되며, 호출 측은 *방향* 만 고른다.

**범위 밖:**

- 색·불투명도 커스텀 — 토큰 고정.
- 단색 딤(dim) 오버레이 — Shade 는 그라데이션 전용.
- 콘텐츠 슬롯 — Shade 는 음영만, 콘텐츠는 호스트가 별도 배치.

## Anatomy

```
┌───────────┐  ← topToBottom
│ ░░░░░░░░░ │     위 투명
│ ▒▒▒▒▒▒▒▒▒ │     아래 음영
└───────────┘
```

- 그라데이션은 화면 기준 수직(위↔아래) 1축.
- *음영이 어느 쪽에 짙은가* 를 방향이 결정.

## 속성

| 항목 | 타입 또는 토큰 | 기본값 | 비고 |
|------|--------------|--------|------|
| `direction` | `Direction` (명세 정의) | `.topToBottom` | 음영 방향. ↓ 값 사전. |

### Direction (값 사전)

| 값 | 음영 위치 |
|----|----------|
| `.topToBottom` | 위 투명 → 아래 음영 (아래쪽이 짙음). 기본값. |
| `.bottomToTop` | 위 음영 → 아래 투명 (위쪽이 짙음). |

## 토큰

색·치수·타이포 등 시각 표현은 `Shade.*` Component Token 이 결정하며, 호출 측은 주입하지 않는다. 토큰 이름·바인딩·값은 **토큰 소스(`ShadeToken` / Token Studio)가 단일 출처** — 본 문서는 목록을 복창하지 않는다. — 방향별 start/end 색 분기 매핑.

음영은 *Black.a10 (10%)* 한 단계만 사용. 방향별 start/end 색을 바꿔, 고정 수직 축에서 음영 위치(아래/위)를 전환한다.

## 불변 규칙

- *그라데이션 전용* — 단색 딤이 아니라 투명→음영 그라데이션.
- *색·불투명도 고정* — `ShadeToken` 이 결정, 호출 측 주입 없음.
- *방향만 선택* — topToBottom / bottomToTop.
- *비상호작용* — 탭·상태 없음.
