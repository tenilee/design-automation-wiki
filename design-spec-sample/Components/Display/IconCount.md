# IconCount

아이콘 + 카운트 숫자를 한 줄로 표시하는 *읽기 전용* 메타 정보 컴포넌트. 찜 수 · 채팅 수처럼 작은 수치 메타를 variant 가 정하는 아이콘과 함께 표시한다. DS 가 아이콘·색·타이포·간격을 결정하고, 호출 측은 수치와 variant 만 지정한다.

## 역할과 범위

작은 수치 메타 정보를 *고정된 아이콘 + 카운트* 한 쌍으로 표시한다. variant 가 의미(찜 / 채팅)를 정하고, 그 의미에 묶인 아이콘은 DS 가 보유한다. 호출 측은 표시할 수치만 넘긴다.

결합 컴포넌트로서 아이콘을 *자기 어휘(variant)* 로 정의하고 내부에서 직접 렌더한다 — 단발 아이콘(Icon)을 합성 재료로 쓰지 않는다 ([SPEC §10.4](../../DESIGN_SYSTEM_SPEC.md#104-결합-캡슐화)).

**범위 밖:**

- 상호작용 — 탭·토글이 필요하면 IconToggle 등 별도 컴포넌트.
- 임의 아이콘 지정 — 아이콘은 variant 가 결정하며 호출 측이 교체할 수 없다.
- 큰 통계 카드 · 독립 액션 버튼 — 작은 메타 표시 전용.
- 카운트 가공 표기(천 단위 구분 등) — 상한 캡(↓ 행동) 외의 표기 규칙은 두지 않는다.

## 다른 컴포넌트와의 구분

| | IconCount | Badge | Icon |
|--|-----------|-------|------|
| 내용 | 아이콘 + 수치 | 텍스트 | 아이콘 |
| 아이콘 결정 주체 | DS (variant 고정) | 없음 | 호출 측 (source) |
| 컨테이너 | 없음 | pill / box | 없음 |
| 상호작용 | 없음 | 없음 | 없음 |

## Anatomy

```
[ icon ]──gap──[ count ]
```

아이콘과 카운트는 수직 가운데 정렬된 한 행. 너비는 내용에 맞춰 hug. 아이콘 크기·gap·카운트 타이포는 `IconCountToken` 이 결정한다.

## 속성

| 항목 | 타입 또는 토큰 | 기본값 | 비고 |
|------|--------------|--------|------|
| `count` | `Int` | — | 필수. 표시 수치. 상한 초과 시 캡 표기(↓ 행동). |
| `variant` | `Variant` (명세 정의) | — | 필수. 의미 + 아이콘을 함께 결정. ↓ 값 사전. |

### Variant

의미 축 2 종. 각 값이 표시 의미와 아이콘을 함께 고정한다.

| 값 | 의미 | 아이콘 |
|----|------|--------|
| `.favorite` | 찜 수 | `SemanticIcon.Product.wishFilled` (하트) |
| `.talk` | 채팅 수 | `SemanticIcon.Product.talkFilled` |

## 행동

- **상한 캡** — `count` 가 99 를 초과하면 `"99+"` 로 표기한다. 99 이하는 숫자를 그대로 표기. (Figma 기본 표기 정렬)

## 토큰

색·치수·타이포 등 시각 표현은 `IconCount.*` Component Token 이 결정하며, 호출 측은 주입하지 않는다. 토큰 이름·바인딩·값은 **토큰 소스(`IconCountToken` / Token Studio)가 단일 출처** — 본 문서는 목록을 복창하지 않는다.

## 불변 규칙

- *상호작용 없음* — 탭 불가. 토글·액션이 필요하면 별도 컴포넌트.
- *아이콘은 variant 가 고정* — 호출 측이 아이콘을 주입·교체할 수 없다.
- *카운트 상한 캡은 DS 소유* — 임계값(99)과 `"99+"` 표기는 DS 행동이며 호출 측이 바꾸지 않는다.
- *너비는 intrinsic* — 내용에 맞춰 hug, 상위 레이아웃에 의해 압축되지 않는다.

## 확장 가이드

### 새 variant 추가 시

1. 새 의미가 기존 `.favorite` / `.talk` 로 표현 불가한지 확인.
2. 의미에 묶일 아이콘을 `SemanticIcon` 에서 선택(없으면 Icon 체계에 먼저 등재).
3. `IconCount.Variant.*` 에 값 + 아이콘 매핑 추가, 본 문서 Variant 표에 한 줄 등재.
