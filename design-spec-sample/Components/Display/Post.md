# Post

포스트 본문을 구성하는 텍스트 블록. `style`(title / subtitle / body)과 `size`(lg / md / sm)로 타이포·색·하단 간격이 결정되며, 세 style 을 쌓아 포스트 본문을 만든다.

> - [SPEC §11.1 분류](../../DESIGN_SYSTEM_SPEC.md#111-분류) — 카탈로그 위치
> - [Components/Display/Text.md](./Text.md) — 텍스트 렌더 기반

---

## 역할과 범위

포스트(에디토리얼·기획) 본문의 *한 텍스트 블록* 을 렌더한다. `style` 로 제목·부제·본문 역할을, `size` 로 3단계 크기를 선택한다. 각 블록은 자기 하단 간격을 포함하므로, 순서대로 쌓으면 포스트 본문 레이아웃이 된다.

**범위 밖:**

- 이미지·미디어 — 별도 컴포넌트 합성.
- 스택 컨테이너 — 호출 측이 title → subtitle → body 순으로 배치한다 (본 컴포넌트는 원자 단위).

## 속성

| 항목 | 타입 또는 토큰 | 기본값 | 비고 |
|------|--------------|--------|------|
| `text` | 문자열 | — | 필수. 표시 텍스트(멀티라인 허용). |
| `style` | `Style` (명세 정의) | `.title` | title / subtitle / body. ↓ 값 사전. |
| `size` | `Size` (명세 정의) | `.lg` | lg / md / sm. ↓ 값 사전. |

### Style

| 값 | 역할 |
|----|------|
| `.title` | 제목 |
| `.subtitle` | 부제 |
| `.body` | 본문 |

### Size

3단계 크기. style 별로 타이포 스케일이 다르게 매핑된다.

| 값 |
|----|
| `.lg` (기본값) |
| `.md` |
| `.sm` |

## 토큰

색·타이포·하단 간격 등 시각 표현은 `Post.*` Component Token 이 style × size 분기로 결정하며, 호출 측은 주입하지 않는다. 토큰 이름·바인딩·값은 **토큰 소스(`PostToken` / Token Studio)가 단일 출처** — 본 문서는 목록을 복창하지 않는다.

## 불변 규칙

- 타이포·색·하단 간격은 `Post.*` 토큰 고정 — 호출자가 변경할 수 없다.
- 하단 간격은 각 블록에 내장되어, title → subtitle → body 를 쌓으면 규정 간격이 자동 확보된다.
- `style` 은 텍스트 역할(제목·부제·본문)만 정하고, 크기는 `size` 축이 직교로 담당한다.
