## 역할과 범위

같은 의미의 아이템을 N 열 그리드로 배치한다. 항상 lazy 렌더링.

**자식 규칙:** 자식은 반복되는 *같은 의미의 단위* (예: 상품 카드들). 헤더 · 본문 · 푸터처럼 *서로 다른 의미의 단위* 는 자식으로 두지 않는다.

같은 의미 안에서 *모양이 조금 다른 변형* 은 허용된다. 예를 들어 일반 상품 카드 사이에 광고 상품 카드가 섞이는 경우, 두 카드는 *같은 의미의 변형* 이라 한 그리드에 들어갈 수 있다. 모양이 다르면 높이도 다를 수 있고 — 이때의 정렬 동작은 아래 *행 높이* 참조.

**범위 밖:**

- 컨테이너 경계 Padding — Section 또는 Page 가 소유.
- 스크롤 — 외부에서 감싼다.
- *벽돌 쌓기 (masonry)* — 짧은 아이템 바로 아래에 다른 아이템이 끼어드는 staggered 배치는 Grid 가 하지 않는다. 별도 컴포넌트 영역.

열 너비는 균등 분할. `gapX` 는 같은 행 내 아이템 사이 Inline 간격, `gapY` 는 행과 행 사이 Stack 간격. 축만으로 명명하고 item / row / column 같은 접두어를 붙이지 않는다 ([§4.3](../../DESIGN_SYSTEM_SPEC.md#43-슬롯-네이밍-규칙)).

## 행 높이

한 행의 높이는 *그 행에서 가장 키 큰 아이템* 의 높이로 정해진다. 같은 행의 다른 아이템들은 *위쪽 끝* 에 맞춰 배치되고, 키가 작은 아이템 아래에는 빈 공간이 남는다.

이 규칙 덕분에 *높이가 조금씩 다른 아이템* (예: 사진만 있는 카드와 사진 + 설명이 있는 카드) 을 한 그리드에 섞어도 자연스럽게 정렬된다.

## 속성

| 항목 | 타입 또는 토큰 | 기본값 | 비고 |
|------|--------------|--------|------|
| `columns` | `Columns` (명세 정의) | `.two` | ↓ 값 사전. |
| `gapX` | `GapX` (명세 정의) | `.md` | 열 사이 수평 간격. 단일 값. |
| `gapY` | `GapY` (명세 정의) | `.xl` | 행 사이 수직 간격. 단일 값. |

### Columns

| 값 | 의미 |
|----|------|
| `.two` | 2 열. 기본값. |
| `.three` | 3 열. |

### GapX

열 사이의 *수평 형제 간격* 이므로 Inline (`GapX`) 을 참조한다.

| 값 | Semantic 참조 |
|----|-------------|
| `.md` | `GapX.md`. 기본값이자 유일 값. |

### GapY

행 사이의 *수직 형제 간격* 이므로 Stack (`GapY`) 을 참조한다.

| 값 | Semantic 참조 |
|----|-------------|
| `.xl` | `GapY.xxl`. 기본값이자 유일 값. |

## 토큰

색·치수·타이포 등 시각 표현은 `Grid.*` Component Token 이 결정하며, 호출 측은 주입하지 않는다. 토큰 이름·바인딩·값은 **토큰 소스(`GridToken` / Token Studio)가 단일 출처** — 본 문서는 목록을 복창하지 않는다.

> Columns 는 토큰화되지 않은 정수 값 (2 / 3).
